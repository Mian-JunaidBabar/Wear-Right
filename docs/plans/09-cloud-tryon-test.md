### Hugging Face free quota (huggingface.co/docs/hub/spaces-zerogpu, checked 2026-10-28)

| Account | Daily ZeroGPU quota |
| --- | --- |
| no login | 2 minutes |
| free account (use an `HF_TOKEN`) | 5 minutes |
| PRO ($9/month) | 40 minutes |

At roughly 10 to 30 seconds per render (to be measured) a free account gives about 10 to 30 renders a day. Enough to pre-render the demo looks over 2 to 3 days. Not enough for live use by visitors, so the app serves cached renders only.

## The test (Prompt 11)

1. Work in a scratch folder `apps/tryon_test/` (gitignored except the report). Separate venv, `pip install gradio_client pillow`.
2. With an `HF_TOKEN` from a free Hugging Face account in the environment, run
   `Client("fashn-ai/fashn-vton-1.5").view_api()` and `Client("zhengchong/CatVTON").view_api()`; paste the output.
   Fix the call parameters to match.
3. Inputs: `men-regular_base.jpg` from the package; 3 real catalog products from `MEDIA_ROOT/products/` (one shirt,
   one T-shirt, one pair of trousers or jeans), using the original product photo.
4. Render: each top on the base photo; then the trousers on the shirt result (two-step). Record seconds per call and
   any queue or quota messages.
5. If FASHN fails, repeat with CatVTON. If both fail and the team has a Gemini key with billing, try
   `call_gemini_vton_api` on the same three.
6. `apps/tryon_test/REPORT.md`: the `view_api` output, the corrected call code, a table (product, model, seconds, OK/failed),
   the input and output images side by side, and a verdict: does the output look like **our** product on the model?

## If the test passes (later plan, not now)

- Django `tryon` app with `TryOnRender` (preset, top, bottom, status, image) and a `prerender_tryon` command that calls
  the Space with the user's `HF_TOKEN` and stops cleanly when the daily quota is hit (resumes tomorrow).
- The outfit board (plan 08) stays the default; a "See it on a model" tab shows the cached render when one exists for
  that top+bottom, and says "Not rendered yet" otherwise. No live generation for visitors.
- Thesis: say plainly that the try-on images come from FASHN VTON v1.5 / CatVTON run on Hugging Face, pre-rendered;
  our part is the skin-tone outfit selection and the pipeline.

## Out of scope for the test

Any change to apps/server or apps/web. Copying the package into the app.
